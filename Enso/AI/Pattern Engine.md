# Pattern Engine

## Overview
The Pattern Engine detects recurring themes, emotions, and behavioral patterns across user journal entries and sessions.

## Pattern Types
- **Emotional Patterns**: Recurring mood states
- **Thematic Patterns**: Topics that appear frequently
- **Temporal Patterns**: Time-based behavior trends
- **Behavioral Patterns**: Actions and habits

## Confidence Scoring
Each pattern has a confidence score based on:
- Frequency of occurrence
- Recency of matches
- Consistency across entries
- Statistical significance

## Pattern Feedback
Users can:
- Acknowledge patterns
- Dismiss patterns
- Provide context for patterns
